# Панель оператора

Локальное приложение Laravel / Filament рядом с «Расписание военмех».
Оно ходит в те же схемы PostgreSQL, включая `operator`. В git этот каталог не входит, в compose сервера его нет.

Zapara.Server страницы `/Admin` не отдаёт: эти пути отвечают 404.
Исходники Razor лежат в `src/Zapara.Server/Pages/Admin` и по HTTP не открываются.

Секреты, `.env`, `vendor` и локальную sqlite в репозиторий не класть.
Картина продукта — `docs/STATUS.md`.

## Двухфакторная защита (TOTP)

Вход в панель поддерживает одноразовые коды из приложения-аутентификатора (RFC 6238: Google Authenticator, Aegis, 2FAS, 1Password и т. п.) и одноразовые коды восстановления. Используется встроенный MFA Filament (`AppAuthentication`), новых пакетов нет.

Секрет и хэши кодов восстановления лежат в таблице `admin_mfa_credentials` (схема по умолчанию подключения панели, рядом с `cache`/`jobs`). Схему `accounts` сервера панель не меняет. Секрет зашифрован `APP_KEY`: при смене ключа старый указывают в `APP_PREVIOUS_KEYS`, иначе администраторам придётся подключать TOTP заново.

### Как администратору подключить

1. Войти в панель по логину и паролю.
2. Меню пользователя (справа вверху) → «Двухфакторная защита» (`/admin/security`).
3. «Настроить» у приложения-аутентификатора, отсканировать QR-код (или ввести ключ вручную), ввести текущий код.
4. Сохранить показанные коды восстановления вне компьютера, с которого входите. Каждый код срабатывает один раз; новые можно выпустить на той же странице.

После этого при входе после пароля спрашивается код. Если телефона нет: «Использовать код восстановления».

### Выкатка без блокировки

1. Деплой с выключенным требованием (по умолчанию `ZAPARA_ADMIN_MFA_REQUIRED=false`) и миграция:
   `docker compose exec admin php artisan migrate --force`.
   Без требования все входят как раньше, подключившие TOTP вводят код.
2. Каждый администратор подключает TOTP по шагам выше.
3. В `admin.env` ставят `ZAPARA_ADMIN_MFA_REQUIRED=true` и перезапускают `admin`. С этого момента администратора без TOTP после пароля сразу отправляют на подключение, в остальные разделы панели без него не пустит.

Пока требование выключено, не подключивший TOTP администратор защищён только паролем. Включайте требование сразу после того, как все подключили.

### Если администратор потерял и телефон, и коды

Оператор с доступом к базе удаляет его строку, после чего администратор подключает TOTP заново при следующем входе:

```sql
DELETE FROM admin_mfa_credentials WHERE user_id = '<user_id из accounts.users>';
```
