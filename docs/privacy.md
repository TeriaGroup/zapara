# Политика конфиденциальности — «Военмех - расписание и карты»

Приложение не требует регистрации и не собирает персональные данные:
нет аккаунтов, аналитики, рекламных SDK и передачи данных третьим лицам.

Что использует приложение и зачем:

- **Интернет** — загрузка расписания с официального сайта БГТУ «Военмех»
  (`voenmeh.ru`) и проверка обновлений. Расписание — публичные данные вуза.
- **Уведомления** — локальные напоминания о парах по времени, выбранному
  пользователем. Формируются на устройстве, никуда не отправляются.
- **Точные будильники / автозапуск после перезагрузки** — чтобы напоминания
  срабатывали вовремя, включая перезапуск AlarmManager после reboot.
- Все данные (группа, переименования, домашние задания, друзья, настройки)
  хранятся только на устройстве пользователя.

Исходный код открыт: `https://github.com/TeriaGroup/zapara`

Контакт разработчика: через страницу репозитория выше.
