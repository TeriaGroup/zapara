# Карточка RuStore — «Военмех - расписание и карты»

## Название (27/30)

Военмех - расписание и карты

## Краткое описание (≤80)

Расписание БГТУ «Военмех»: пары, карты корпусов, друзья, домашка и напоминания. Офлайн.

## Полное описание (≤4000)

Расписание БГТУ «Военмех» без блужданий по катакомбам ГК и УЛК.

- Пары: вчера / сегодня / завтра / неделя / сводка, умный стартовый день,
  чётность недели, столбец следующей пары.
- Группа выбирается один раз из полного списка (~420) с поиском.
- Переименования предметов и домашние задания со сроками и напоминаниями.
- Друзья-светофоры: кто в той же аудитории, на этаже, в корпусе.
- Карты корпусов офлайн: ГК 1–4 и УЛК 1–5, следование за парой, поиск по корпусам.
- 700+ преподавателей: поиск, фильтр «только мои», неделя с фильтром чётности.
- Уведомления утром и вечером. Обновления приходят через RuStore.

Данные расписания — с официального сайта voenmeh.ru, обновляются автоматически.
Без регистрации, без рекламы, работает офлайн.

## Служебное

- Категория: Образование. Возраст: 0+.
- package: `ru.zapara.app`. Подпись: релизный ключ (JKS вне репозитория).
- Сборка для стора: `.\gradlew.bat :app:assembleRustoreRelease`
  (флавор `rustore`: без самообновления и без REQUEST_INSTALL_PACKAGES).
- Иконка: `docs/dist/icon-512.png` (512×512).
- Разрешения и зачем:
  - INTERNET — загрузка расписания с voenmeh.ru;
  - POST_NOTIFICATIONS, SCHEDULE_EXACT_ALARM, RECEIVE_BOOT_COMPLETED —
    локальные напоминания о парах, включая перезагрузку;
  - ACCESS_NETWORK_STATE / ACCESS_WIFI_STATE — проверка сети перед обновлением расписания.
- Модератору: вход не нужен, весь функционал доступен сразу; группа по
  умолчанию подбирается автоматически, карты и расписание преподавателей
  встроены и работают без сети.
