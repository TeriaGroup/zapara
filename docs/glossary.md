# Глоссарий и правила текста (web и desktop)

Одинаковые понятия называются одинаково на всех платформах. Строки из таблицы ниже лежат в общем каталоге
`design/strings/ru.json`; после правки каталога запустите `node scripts/design/strings.mjs` — он обновит
`web/src/strings.gen.ts` и `src/Vograph.Core/Services/SharedStrings.g.cs`. Тест `web/src/strings-catalog.test.ts`
падает, если файлы устарели, если ключ каталога продублирован в `I18nService`, если где-то написано «...»
или известное слово без «ё».

## Термины

| Понятие | Как пишем | Не пишем |
|---|---|---|
| Занятие в расписании | **пара** | урок, занятие (в интерфейсе) |
| Промежуток между парами < 90 мин | **перерыв** | окно |
| Промежуток ≥ 90 мин | **окно** | перерыв, пауза |
| Раздел с заданиями | **домашка** | ДЗ, задания (как название раздела) |
| Одна запись в домашке | **задание** | домашка, таск |
| Отметка о выполнении | **выполнено**, фильтр — «Выполненные» | готово у меня, сдано |
| Чётность недели | **чётная / нечётная**, коротко «чёт. / нечёт.» | четная, нечетная |
| Учебная группа (А863С) | **группа** | класс |
| Пространство группы в приложении | **сообщество** | группа (в этом смысле) |
| Роль в сообществе | **староста** | админ, модератор |
| Название раздела с днём | **Расписание** («Сегодня», «Завтра» — только переключатель дня) | Сегодня (как заголовок страницы) |

Действия: «Карта», «Обсудить в чате группы», «Добавить задание», «К срокам домашки».
Счётчики: «открыто 5 · выполнено 2». Этаж: «2 этаж»; в компактном выборе — подпись «Этаж» и номера.

## Форматы

- Дата: «9 окт.»; год — только если не текущий: «30 дек. 2025».
- Дата и время: «9 окт., 18:31»; время по Москве с пометкой — «18:31 МСК».
- Диапазон — короткое тире без пробелов: «5–11 окт.», «28 сент.–4 окт.».
- Ввод даты — «дд.мм.гггг».
- «ё» всегда. Многоточие — один символ «…».
- Заголовки, кнопки и подписи — с заглавной только первое слово (sentence case), без капса.
- Вторичный текст — не меньше 13 px (шкала G-1, #50).

## Строки расписания

Фид отдаёт строки как есть («пр УПР.ПРОЕКТАМИ», «268*(фесто);», «Кондратьев Сергей А.»). Для показа их
нормализуют `web/src/schedule-text.ts` и `src/Vograph.Core/Services/ScheduleText.cs` — один алгоритм, общие примеры
в `design/strings/schedule-cases.json`. Ключи (`subjectRaw`, переименования, домашка) не меняются.

- Префикс типа («лек», «пр», «лаб»…) убирается — тип показывает чип: «Лекция», «Практика», «Лабораторная».
- Предмет: словарь `subjects` в каталоге (короткое имя в строке, полное — в подсказке/листе пары); остальное —
  читаемым регистром: сокращения со точкой и слова — строчными, аббревиатуры (без гласных или из списка
  `abbreviations`) — заглавными, пробел после точки и запятой. Названия, которые студент задал сам, не трогаются.
- Аудитория: без «*» и «;», «268 (Фесто)», несколько — через запятую.
- Преподаватель: «Фамилия И. О.»; полное имя превращается в инициал.
- Пустые поля в строке метаданных не выводятся, висящих «·» нет.
