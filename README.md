# Военмех - расписание и карты

Расписание БГТУ «Военмех»: пары, карты корпусов, друзья, домашка и уведомления.
Два приложения с общей логикой — Windows и Android. Офлайн из коробки, без сервера и облака.

Актуальные версии и файлы — на странице релизов: `https://github.com/TeriaGroup/zapara/releases`

## Приложения

- **Windows** — WPF, .NET 8, интерфейс на русском и английском (переключение без перезапуска).
- **Android** — Kotlin + Compose, интерфейс на русском, Android 8.0+.

## Что умеет

- **Расписание: Вчера / Сегодня / Завтра / Неделя / Сводка.** Умный старт: если сегодняшние пары еще не прошли — открывается сегодня, иначе завтра.
- **Четность.** Неделя с 1 сентября = неделя 1 = нечетная. Есть ручная инверсия, если вуз сдвинул неделю.
- **Столбец «След.»** — дата следующего занятия по предмету.
- **Сводка** — нечетная / четная / обе недели: по дням, типам, предметам, преподавателям, аудиториям.
- **Выбор группы** — все ~420 групп с поиском. Выбирается один раз и запоминается.
- **Переименования предметов** — глобально или только на день недели, плюс заметки. Переживают обновление расписания.
- **Домашние задания** — «через N пар», срок вычисляется сам по расписанию. Статусы: скоро / горит / горит сегодня / просрочено / сдано (далекие скрыты). Текст и срок правятся карандашом у задания.
- **Друзья-светофоры** — до 5 групп: та же аудитория / тот же этаж / тот же корпус / в вузе / нет рядом (потухший). Режим «всегда все» или «только непустые», имена товарищей, добавление через поиск.
- **Карты корпусов офлайн** — 9 планов: ГК 1–4 и УЛК 1–5, встроены в приложение. Аудитория со `*` — это УЛК, без `*` — ГК, `ВЦ` показывает план ГК с пометкой, дистанционные пары — без карты. Карта сама следует за следующей парой, кнопка `◉` у пары показывает её корпус, отдельная кнопка «Карта» — выбор по корпусам. Зум, панорама, на весь экран, «Сбросить вид».
- **Преподаватели** — 700+ человек из расписания вуза: поиск, фильтр «только мои», неделя преподавателя с фильтром Обе / Нечет / Чет, подсветка сегодняшнего дня и пар вашей группы.
- **Уведомления** — два времени: вечернее рассказывает про завтра, утреннее — про сегодня, с переименованными предметами и пометкой горящего ДЗ. На Android — точные будильники, переживают перезагрузку телефона.
- **Синхронизация по локальной сети (Windows)** — перенос переименований, ДЗ, друзей и настроек между устройствами: JSON-файл + QR + `http://<ip>:8765/sync`. Без облака.
- **Автообновление** — оба приложения сами проверяют релизы на GitHub при старте, скачивают и ставят (Android открывает системный установщик, Windows перезапускается сам). Отключается в настройках.

## Установка

- **Android:** `ZAPARA_android-debug.apk` ставится сразу; `ZAPARA_android-release-unsigned.apk` требует подписи. Или через ADB: `adb install -r ZAPARA_android-debug.apk`.
- **Windows:** распаковать `ZAPARA_win-x64.zip` и запустить `Vograph.exe` (нужен .NET 8 Runtime).

## Источники данных

- Студенты: `https://voenmeh.ru/obrazovanie/timetables/` → `.../_voenmeh_grafics/TimetableGroup50.xml` (~5.6 МБ, ~420 групп).
- Преподаватели: страница расписания преподавателей → `TimetableLecturer50.xml` (встроен в приложения + кэш).
- Карты: `https://voenmeh.ru/openmap/` → планы `karta-*-2022.jpg` (ГК 1–4, УЛК 1–5), встроены в приложения.
- Расписание перепроверяется само раз в сутки (`HEAD If-Modified-Since`); переименования и ДЗ при этом не теряются.

## Хранение

- Windows: `%LocalAppData%\Vograph\` — SQLite `vograph.db` (WAL), кэш карт, скачанные обновления.
- Android: приватное хранилище приложения — база Room, кэш карт, скачанные APK.

## Сборка из исходников

Windows (PowerShell, .NET 8 SDK):

```powershell
dotnet publish src\Vograph\Vograph.csproj -c Release -r win-x64 --self-contained false
```

Android:

```powershell
cd android
.\gradlew.bat :app:assembleGithubDebug
.\gradlew.bat :app:testGithubDebugUnitTest
# Сборка для RuStore (без самообновления): :app:assembleRustoreRelease
```

## Структура

```text

android/app/src/main/        # Android-клиент: Compose-экраны, Room, будильники, автообновление
docs/API.md                  # Разбор XML/XSL/parity/openmap/lecturer
docs/PROGRESS.md             # Верификация Windows по фазам
docs/PROGRESS_ANDROID.md     # Верификация Android по фазам
docs/dist/                   # Готовые сборки
data/runs/                   # Логи авторефреша / уведомлений / синхронизации
```
