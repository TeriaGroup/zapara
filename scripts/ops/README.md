# Локальная репетиция backup/restore

Скрипт `Backup-Restore-Rehearsal.ps1` проверяет цепочку `pg_dump` → удаление таблицы → восстановление только на локальной синтетической БД `zapara_test` (loopback `127.0.0.1:56432`).

## Требования

- Подготовленный локальный PostgreSQL 16 с БД `zapara_test` на порту `56432` (контейнер/служба уже запущены оператором).
- Переменная `ZAPARA_TEST_POSTGRES` (формат Npgsql) на этот же целевой инстанс; при наличии подключается private helper окружения платформы.
- В `PATH`: `psql.exe`, `pg_dump.exe`.
- Скрипт **не** стартует и **не** останавливает PostgreSQL и **не** вызывает `docker compose down`.

## Запуск

```powershell
& .\scripts\ops\Backup-Restore-Rehearsal.ps1
```

Создаётся собственная схема `ops_rehearse_<hex>`, одна таблица и строка; дамп пишется в `%TEMP%\opencode\zapara-ops-<stamp>\backup.sql`. После проверки схема удаляется. Повторный запуск не должен оставлять `ops_rehearse_*`.

## Коды выхода

| Код | Смысл |
|-----|--------|
| 0 | Успех: дамп непустой, строка восстановлена, схема убрана |
| 2 | Небезопасная или отсутствующая цель (не `127.0.0.1:56432` / `zapara_test`) |
| 5 | Ошибка дампа, восстановления или проверки |

Строки подключения и секреты в вывод не печатаются. Это локальная репетиция, не подтверждение продакшен-бэкапа.
